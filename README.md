Meta Mapping functionality for [LD-Archive.org](https://www.ld-archive.org), to enable searching the site's custom metadata.

## About

The site [ld-archive.org](https://ld-archive.org) uses [Jetpack Search](https://jetpack.com/upgrade/search/)
to deliver search results to users of the site. The deafault [Wordpress.com](https://wordpress.com) search doesn't search any custom metadata.

After having tried a few options. This custom plugin seemed like the easiest solution.
It makes use of the template from the FAQs on Jetpack Search, which you can find on [the Jetpack Search Webpage](https://jetpack.com/support/search/frequently-asked-questions/).

## Running on the Site
In order for this to work on the site, it needs to be zipped and uploaded to the Wordpress Admin Plugins page. Manual updating is required for any changes. 

1. Visit the [Releases](https://github.com/ld-archive/jetpack-search-meta-map/releases) page and download the `.zip` file.
2. Go to the Wordpress Admin Plugins page (_site admins only_).
3. Upload the `.zip` file. You may need to delete the previous plugin version.

For more information you can visit the [Jetpack Search FAQ](https://jetpack.com/support/search/frequently-asked-questions/)
